# Library Management System 📚

A console-based Library Management System developed in C++ that efficiently manages books, members, and borrowing records using Object-Oriented Programming and file handling.

## Features
- 📖 Add new books to library
- 👤 Add new members
- 📋 Display all books
- 👥 Display all members
- 📤 Issue book to member
- 📥 Return book from member
- 🔍 Search book by title
- 🔍 Search book by author

## Technologies Used
- Language: C++
- Concepts: OOP, File Handling, Classes, Encapsulation
- Platform: Windows (Console Application)

## OOP Concepts Used
| Concept | Description |
|---------|-------------|
| Classes | Book and Member classes |
| Encapsulation | Private data members |
| Constructors | Default constructors |
| Methods | issue(), return(), search() |
| File Handling | Separate .dat files for books and members |

## How to Run

### Prerequisites
- g++ compiler (MinGW-W64)

### Compile & Run
```bash
g++ library.cpp -o library
library.exe
```
